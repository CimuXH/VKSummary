#### 3.开发中遇到的任何问题：
- 1. 前端调用视频字幕获取api的时候，api内部会去调用bilibili库的接口，如果视频很多请求时间会很长，导致前端链接超时，
**解决方法：**前端请求直接返回任务id，后端启动后台任务慢慢请求，然后前端使用轮询方式查看任务进度.
- 2. 但是后来还有agent后台任务，这样启动这个任务还要再写一个接口轮询请求（两个任务不在同一个函数中实现，用同一个全局字典查看进度懒得改了）。
**解决方法：**用sse，在任务过程中任务进度消息推送到全局队列中，接口循环订阅消息给前端。
- 3. 后台任务启动之后要引用一下，要不然任务长时间没有人引用会被GC，所以任务启动之后就加入到全局set中，完成之后就删除这个任务。全局变量不会被GC。
**解决方法：**引用一下。
- 4. 同步请求每个视频字幕内容太慢了。
**解决方法：**控制并发数，然后使用asyncio.father()来并发处理请求，father会等待所有并发任务都完成再回返回所有结果。
- 5. 并发中不能使用requests请求库，这个库是同步的。
**解决方法：**使用并发库httpx
- 6. 异步函数的任务就是解决 耗时 操作
